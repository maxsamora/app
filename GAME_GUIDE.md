# 🎮 The Secret Admirer Game - User Guide

## 🎵 Background Music
- **Song**: "One Dance" by Drake
- **Auto-plays** when the game starts (when clicking "INITIALIZE SYSTEM")
- **Loops continuously** throughout the game
- **Volume Control**: Click the speaker icon in the top-right corner to mute/unmute

## 🎯 How to Play

### Start Screen
1. Read the birthday message for Solène Delacourt
2. Review the mission briefing
3. Click **"INITIALIZE SYSTEM"** to begin
4. Music will start playing automatically

### Quiz Game (10 Questions)
1. Each question has a **unique animated Friends GIF background**
2. Type your answer in the terminal-style input field
3. Press **Enter** or click **"SUBMIT ANSWER"**
4. Get **hints after 2 wrong attempts**
5. Track your progress with the progress bar
6. Watch for romantic hacker messages between questions

### Final Victory Screen
1. Reveals Maxwell as the secret admirer
2. Floating hearts animation
3. Link to Maxwell's Instagram
4. Terminal-style success message

## 🎨 Features

### Visual Design
- **Hacker terminal aesthetic**: Black background, neon green/purple text

- **Friends GIF backgrounds**: Different for each question
